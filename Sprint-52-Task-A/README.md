# Task A: Prepare A Mandarin Dataset For Human Review (Continued task)

User story: As a team, we want to create a Mandarin dataset that can be sent out for human review, so we can get fresh, trustworthy labels for the Mandarin judge.

Acceptance criteria:

Select additional examples per direction, sourced independently of the original borrowed data.

Examples should span a range of quality levels, not just clean, easy sentences.

Each example should record where it came from, for traceability.

A target number of examples per direction should be set upfront.

Package the examples with clear scoring instructions and a defined rubric a reviewer can follow without needing clarification.
